Betterlink 0.3.1 fixes a crash on macOS 27.

## Fixed

On macOS 27, Betterlink quit a few seconds after launch — usually before its
window appeared — whenever it opened on the Dashboard. The camera control bar
under the viewfinder and the camera adjustments inspector were competing for
the same width, and macOS 27 kept re-running layout until it gave up and
terminated the app. Earlier macOS releases tolerated the same layout, so this
only appeared after updating.

The control bar now scrolls horizontally when the window is too narrow for it,
the same way the favorites strip does, instead of forcing a minimum width on
the window. At normal window sizes it looks exactly as before.

If 0.3.0 is crashing for you, the in-app updater may not stay open long enough
to install this release: download the DMG below and drag Betterlink to
Applications.
